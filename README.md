Python Strings & Tuples – Short Notes

Strings
A string is a sequence of characters enclosed within single or double quotes.

1. String Concatenation
Used to join two or more strings.
Syntax:
string1 + string2

3. String Indexing
Used to access individual characters. Indexing starts from 0.

Syntax:
string[index]

3. String Slicing
Used to extract a part of a string.

Syntax:
string[start:end]

4. Reverse a String
Used to display a string in reverse order.

Syntax:
string[::-1]

5. Uppercase
Converts all characters to uppercase.

Syntax:
string.upper()

6. Lowercase
Converts all characters to lowercase.

Syntax:
string.lower()

7. Capitalize
Converts the first character of a string to uppercase.

Syntax:
string.capitalize()

8. Count
Counts the number of occurrences of a character or substring.

Syntax:
string.count(value)

9. Replace
Replaces a specified value with another value.

Syntax:
string.replace(old, new)

Tuples
A tuple is an ordered collection of elements. Tuples are immutable, meaning their values cannot be changed after creation.

1. Tuple Creation
Used to create a tuple containing multiple values.

Syntax:
tuple_name = (value1, value2, value3)

2. Tuple Concatenation
Used to combine two or more tuples.

Syntax:
tuple1 + tuple2

3. Tuple Repetition
Repeats the elements of a tuple a specified number of times.

Syntax:
tuple_name * number

4. Tuple Indexing
Used to access an individual element from a tuple.

Syntax:
tuple_name[index]

5. Tuple Slicing
Used to access a specific range of elements.

Syntax:
tuple_name[start:end]

Key Points

Strings
Strings are sequences of characters.
Strings can be created using single or double quotes.
Indexing is used to access individual elements.
Slicing is used to extract a range of elements.
Strings support methods such as:
upper()
lower()
capitalize()
count()
replace()

Tuples
Tuples are ordered collections.
Tuples are immutable.
Tuples support indexing and slicing.
Tuples support concatenation and repetition.
Strings and Tuples

Both strings and tuples support:

Indexing
Slicing
Concatenation
Repetition
